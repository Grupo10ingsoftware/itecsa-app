# Data

Durante el desarrollo, esta carpeta contiene archivos generados o subidos localmente por flujos del backend.

`data/NVS` almacena Notas de Venta dummy asociadas a pedidos durante el desarrollo. La confirmacion de pago no modifica estos archivos.

No versionar documentos reales, datos personales sensibles, contrasenas ni tokens. Los archivos de usuario deben tratarse como datos locales de desarrollo o de ambiente.
