# Orders / Ventas

Registro de pedidos desde una nota de venta consultada por API. El borrador se mantiene en memoria React y el servidor recupera la fuente al confirmar.

La referencia de contrato, persistencia, interfaz y límites se mantiene en [Orders](../../../../docs/modulos/ORDERS.md). Consultar también la [migración pendiente](../../../../docs/operacion/ORDERS_MIGRACION.md) y las [pruebas](../../../../docs/desarrollo/PRUEBAS.md).
